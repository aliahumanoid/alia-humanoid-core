Suggested sequence

  1. 1. Select the joint and DOF to test.
  2. 2. Keep or restore the waypoint-safe defaults: outer Kp={{ '%.2f'|format(impedance_defaults.outer_kp) }}, Ki={{ '%.2f'|format(impedance_defaults.outer_ki) }}, Kd={{ '%.2f'|format(impedance_defaults.outer_kd) }}, inner Kp={{ '%.2f'|format(impedance_defaults.inner_kp) }}, Ki={{ '%.2f'|format(impedance_defaults.inner_ki) }}, Kd={{ '%.2f'|format(impedance_defaults.inner_kd) }}, stiffness={{ '%.1f'|format(impedance_defaults.stiffness) }}°.
  3. 3. Enable impedance mode.
  4. 4. Run Init Gains + Hold once to seed the controller at the current encoder position without moving.
  5. 5. Send a single goal or start the 50 Hz stream.

Init Gains + Hold seeds the current outer PID + cascade into firmware RAM, sends the current outer/inner gains, stiffness and tau_ff, then forces q_goal to the current encoder position so the mode starts from hold instead of from a motion step.
